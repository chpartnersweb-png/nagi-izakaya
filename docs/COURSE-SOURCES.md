## 実装箇所

- src/data/courses.ts：コース名・価格・人数・品数・説明・参照URL
- src/components/CourseSection.astro：お品書きと日本酒の間に新設。各プランから指定の食べログ店舗トップへ遷移
- src/data/site.ts：食べログURLとページ内コースナビゲーション
- SiteHeader.astro：PCの食べログ予約ボタンとモバイルナビ内の食べログリンク
- AccessSection.astro：電話導線に食べログ予約ボタンを追加
- SiteFooter.astro：食べログリンク

営業時間・席数等には、提供情報と食べログの相違があった。依頼されたコース情報・リンク追加の範囲で反映し、既存の店舗基本情報は書き換えていない。

## ヒーローの全画面対応

src/styles/global.cssでデスクトップの620px・モバイルの510pxという固定最小高を外し、100vh → 100svh → 100dvhの順にフォールバックする高さへ統一した。モバイルの固定ボタン分をヒーローの高さから差し引く指定は削除。背景画像はobject-fit: coverで全領域を覆い、ロゴとコピー全体は縦横中央に配置する。

固定ボタンにヒーロー下端の文字が隠れないよう、下端のアクセス・スクロール・イメージ表記だけを上げている。低い画面ではロゴと余白を縮め、モバイルの補助案内を省略してイメージ表記を残す。

実装後のビルド・ブラウザ・リンク動作確認は、ユーザーの指定により実施していない。
